# B6：图书视频绑定

> **阶段**：B6 · **周期**：1～2 天  
> **目标**：实体书绑定媒资 VIDEO；未解锁试看播放；借阅 / 已购完整播放。  
> **上一篇**：[B5 Study Agent](./B5-StudyAgent.md)　**下一篇**：[附录-联调样例](./附录-联调样例.md)

---

## 本步要做什么

使用 B1 已建的 `book_media_ref`。播放签名由书城鉴权后再调媒资 `GET /internal/medias/{fileId}/play-url` + Token；密钥不下发浏览器。

细节可对照 [对接指南 M2～M3](../../../video/docs/15-对接智慧书城/01-媒资平台与智慧书城分步实现指南.md)，不必改媒资 Worker。

---

## 接口（建议）

```text
# 管理
POST   /api/admin/books/{bookId}/media
  # body: fileId, title?, mediaType=INTRO, previewSeconds=300, sortOrder?
GET    /api/admin/books/{bookId}/media
DELETE /api/admin/books/{bookId}/media/{refId}

# 用户
GET /api/books/{bookId}/media
  # 列表：无长期 playUrl

GET /api/books/{bookId}/media/{refId}/play
  # 书城判定权限 → Client.getPlaySignature(fileId, preview)
  # 返回短时 playUrl（或 path + 签名参数）
```

权限：

| 用户状态 | preview |
| --- | --- |
| 未借阅 / 未购 | `preview=true`（或媒资现网试看参数） |
| 借阅中 / 已购 | `preview=false` |
| 归还后 | 恢复试看 |

列表接口**不得**下发可长期使用的播放地址。

---

## 验证

```text
1. ADMIN 绑定一个已 FINISHED 的 VIDEO fileId
2. 未登录或未借阅：play 为试看；超时后签名失效
3. 借阅后：完整播放
4. 归还后：再变试看
5. fileId 不存在 → 明确错误（勿 500 堆栈）
6. 阅读试看（B3）与视频试看互不污染错误码
```
