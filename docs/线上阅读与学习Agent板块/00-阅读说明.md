## 本板块做什么

在书城落地：**线上书目录、试看、笔记、学习 Agent（总结 / 改写 / 合并）**，以及图书配套视频绑定与播放。

正文**不进书城库**。`ebook_chapter` 只存目录 + `chapter_file_id`；读章经 BFF 向媒资拉文本。

口诀：**权限在书城，文件在媒资，目录在书城。**

| 做 | 不做 |
| --- | --- |
| TOC、试看 5103、借阅解锁 | FFmpeg、MinIO、切章正则执行 |
| 笔记 CRUD、进度 | 持久化章正文 `MEDIUMTEXT` |
| Study Agent（独立 Prompt） | 与客服共用 `AiChatConfig` |
| `LiteMediaClient`（可 Mock） | 直连媒资 MySQL / MinIO |

---

## 使用方式

1. 确认书城可登录；媒资侧 L3～L4 可用，或全程 `mock=true`
2. 从 **B0** 做到 **B6**，每步末尾「完成标准」全部勾选再进下一步
3. 表结构 / 错误码 / 配置以 [总纲](../线上阅读与学习Agent板块分步实现指南.md) 为准；本目录只讲「改哪里、怎么验」
4. B2～B3 先 Mock 演示，再切真实 `fileId`（见媒资 [附录-联调样例](../../../video/docs/16-媒资平台板块/附录-联调样例.md)）
5. 客服 `/api/ai/chat` 行为必须保持不变（回归）
