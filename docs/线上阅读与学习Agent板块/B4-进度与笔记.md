# B4：进度与笔记

> **阶段**：B4 · **周期**：2 天  
> **目标**：阅读进度续读；手动 / 划线笔记 CRUD；用户隔离；锁定章防泄文。  
> **上一篇**：[B3 试看 BFF 读章](./B3-试看BFF读章.md)　**下一篇**：[B5 Study Agent](./B5-StudyAgent.md)

---

## 本步要做什么

进度与笔记只引用书城侧 `ebook_id` / `chapter_id`（库内主键），**不存章正文副本**（划线 `quote_text` 可短摘录）。

接口形态可对照 [AI 阅读笔记 R2](../AI阅读笔记模块分步实现指南.md)，以本板块表结构为准。

---

## 接口（建议）

```text
PUT  /api/reader/ebooks/{ebookId}/progress
  # body: chapterNo 或 chapterId, charOffset

GET  /api/reader/ebooks/{ebookId}/progress

POST /api/reader/notes
  # body: ebookId, chapterId?, title?, content, quoteText?, tags?
  # source_type 默认 MANUAL；划线用 HIGHLIGHT

GET    /api/reader/notes?ebookId=
GET    /api/reader/notes/{noteId}
PUT    /api/reader/notes/{noteId}
DELETE /api/reader/notes/{noteId}
```

权限：

| 规则 | 行为 |
| --- | --- |
| 笔记归属 `user_id` | 仅本人读写删 |
| 他人笔记 | 5201 |
| 划线过长且章节对用户锁定 | 拒绝保存（防泄文） |
| 可对试看章做笔记 | 允许 |

`source_type` 枚举预留：`MANUAL` / `HIGHLIGHT` / `AI_SUMMARY` / `AI_REWRITE` / `AI_MERGE` / `VIDEO_SUMMARY`（后三者 B5 / B6）。

---

## 验证

```text
1. USER A 写进度与两条笔记
2. 再登录可见同一进度；换章更新 char_offset
3. USER B 改 / 删 A 的笔记 → 5201
4. 对锁定章提交超长 quote_text → 拒绝
5. 列表按 ebookId 过滤正确
```

---

## 完成标准

- [ ] 进度按用户 × 书唯一 upsert
- [ ] 笔记 CRUD + 用户隔离（5201）
- [ ] 划线 / 手动 `source_type` 正确
- [ ] 锁定章防泄文策略有测试
- [ ] 不写入章全文到笔记表（除短摘录）
