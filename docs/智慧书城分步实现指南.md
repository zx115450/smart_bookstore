| 你的情况 | 建议读法 |

**原则**：

1. **每阶段结束必须可演示**（接口通 + 自测清单打勾）
2. **先业务真相源（MySQL），再缓存 / MQ / 向量**
3. **测试与功能同阶段补最小集**；不要等到全部做完再写测试
4. **不跨阶段堆功能**（例如借阅状态机未通不开秒杀）

## 1. S0：工程基座

**目标**：Spring Boot 工程可启动，分层与配置约定固定，后续模块只「往里填」。

### Step 0.1 技术选型锁定

| 项 | 本仓库约定 |
| --- | --- |
| 语言 / 框架 | Java 21、Spring Boot 4.1 |
| Web / 安全 | Spring MVC、Spring Security、JWT |
| 持久化 | MyBatis-Plus 3.5.9、MySQL 8+ |
| 缓存 / 消息 | Redis、RabbitMQ |
| AI（后做） | Spring AI 2.0、DeepSeek Chat、千问 Embedding、可选 Milvus |
| 构建 | Maven、`maven-surefire-plugin` |

### Step 0.2 包结构（按业务域）

```text
com.zx
├── auth/          认证与 RBAC
├── reservation/   自习室预约
├── marketing/     签到等营销
├── bookstore/     catalog / borrow / cart / coupon / trade / seckill
├── ai/            客服、FAQ、推荐、RAG
├── admin/         管理端聚合
├── common/        统一 DTO、ErrorCode
└── config/        全局配置
```

分层约定：`controller → service → repository → mapper/entity`。

### Step 0.3 统一约定

| 约定 | 说明 |
| --- | --- |
| 错误码分段 | 见 `ErrorCode`：认证 1xxx、预约 3xxx、书城 4xxx、AI 5xxx |
| 配置外置 | 密钥走环境变量 / `application-local.yaml`（勿提交密钥） |
| SQL 初始化 | 开发可用 `spring.sql.init`；生产改为 `never` |
| 端口 | 默认后端 `8081`（以 `application.yaml` 为准） |

### Step 0.4 环境最小集

```text
□ JDK 21+
□ Maven 3.9+
□ MySQL 8.0+
□ Redis 6+
□ RabbitMQ 3.8+（秒杀 / 订单超时前必须）
□ Milvus 2.6+（仅启用 ai.rag.enabled 时）
□ Apifox / Postman
```

**S0 验收**：

```text
□ mvn -DskipTests package 成功
□ 应用能连上 MySQL / Redis 并启动（无业务模块也可空跑）
□ ErrorCode 区间文档可读
```

## 2. S1：认证与权限

**目标**：三种登录方式 + Access / Refresh 双 Token + `USER` / `ADMIN` 方法级权限。

### 分步

| 步骤 | 任务 | 关键类 / 接口 |
| --- | --- | --- |
| 1.1 | 用户表、Refresh Token 表、登录审计 | `auth` 实体 / Mapper |
| 1.2 | `JwtService` 签发与校验 | Access 短、Refresh 长 |
| 1.3 | 密码登录、邮箱验证码登录 | `POST /api/auth/login`、`/code/send` |
| 1.4 | QQ OAuth（可后置） | `QqOAuthService` |
| 1.5 | Refresh / Logout / 会话黑名单 | `POST /api/auth/refresh`、`/logout` |
| 1.6 | Security 过滤器链 + `@PreAuthorize` | 保护业务接口 |

**S1 验收**：

```text
□ 密码登录拿到 accessToken + refreshToken
□ access 过期后 refresh 成功；logout 后 refresh 失效
□ USER 调 ADMIN 接口返回 403 / 业务拒绝码
□ 发码频率限制生效（防刷）
```

**建议同步测试（最小）**：`JwtService` 单元测试；登录成功路径 MockMvc（见 T2）。

## 3. S2：预约 + 签到

**目标**：到馆主线 —— 约座位 → 到场签到 → 连续签到满 7 天发券。

### 3.1 预约

| 步骤 | 任务 | 要点 |
| --- | --- | --- |
| 2.1 | 资源 / 时段 / 座位 / 预约单表 | 座位级库存 |
| 2.2 | 浏览资源与时段 | `GET /api/reservation/resources`、`.../slots` |
| 2.3 | 提交预约（乐观锁 / 行锁防超卖） | `POST /api/reservation/orders` |
| 2.4 | 我的预约、取消 | 状态机合法迁移 |

### 3.2 签到营销

| 步骤 | 任务 | 要点 |
| --- | --- | --- |
| 2.5 | 签到窗口 + 场馆码校验 | `GET /api/checkin/eligible`、`POST /api/checkin` |
| 2.6 | 连续签到 streak（可用 Bitmap） | `GET /api/checkin/streak` |
| 2.7 | streak 达 `checkin.streakRewardDays` 发 `CHECKIN_7` 券 | 与 coupon 模块联动 |

**S2 验收**：

```text
□ 同一座位同时段第二次预约失败
□ 窗口外签到失败；正确场馆码可签到
□ 连续 7 天（或把配置调小便于测）后账户有券
```

## 4. S3：书城流通（图书 → 借阅 → 购书 → 秒杀）

**目标**：图书流通与交易闭环。细节按 [书城系统分阶段实施指南](./书城系统分阶段实施指南.md) 的 P0～P5 执行，此处只给依赖顺序。

```text
P0 图书目录 + Redis 详情缓存
 → P1 借阅状态机（APPLIED → BORROWED → RETURNED / OVERDUE）
 → P2 已与签到联动（若 S2 已做可跳过重复）
 → P3 购物车 + 购书订单 + 优惠券核销 + 未支付延迟取消（RabbitMQ）
 → P4 秒杀 Lua 扣减 + MQ 异步发券
 → P5 管理端图书 / 分类 / 书架 + 联调
```

### 借阅状态机（必懂）

```text
APPLIED（待取书）
  ├─ confirm → BORROWED → return → RETURNED
  │                └─ 到期扫描 → OVERDUE → return → RETURNED
  └─ cancel / reject → CANCELLED
```

库存要点：申请可不扣借阅库存；确认借出再扣；归还回补。逾期可用 Redis ZSET + Lua（见相关学习文档）。

### 购书 / 秒杀要点

| 能力 | 要点 |
| --- | --- |
| 购书 | `PENDING_PAY` → 支付 / 取消；未支付延迟消息自动取消并回库存 |
| 优惠券 | 满减 / 百分比；核销事务与订单同事务 |
| 秒杀 | Redis Lua 原子扣库存 → MQ → 落库发券；消费须幂等 |

**S3 验收**（摘最关键）：

```text
□ 图书列表 / 详情；详情二次命中 Redis
□ 借阅：申请 → 确认 → 归还全流程
□ 下单用券支付成功；未支付超时自动取消
□ 秒杀超卖不发生；重复消费不重复发券
```

## 5. S4：AI 客服（Tool + 可选 RAG）

**目标**：对话入口 + Tool 查真数据；向量只做语义召回。细节见 [AI模块分板块实施流程](./AI模块分板块实施流程.md)。

### 推荐实施顺序

| 板块 | 内容 | 可演示问题 |
| --- | --- | --- |
| A | Spring AI + DeepSeek 单轮 | 「你好」 |
| B | `/api/ai/chat` + Redis 多轮记忆 + 限流 | 多轮续聊 |
| C | 查书 / 详情 Tool + cards | 「有没有 Redis 书」 |
| D | FAQ 关键词（后可加向量） | 「怎么借书」 |
| E | 个人借阅 Tool（需登录） | 「我借的书在哪」 |
| F | 规则推荐（热门 / 分类 / 个性化） | 「推荐技术书」 |
| G | Milvus：书目 + FAQ 同 collection `bookstore_book`，`type` 分区 | 模糊语义问法 |

**心智模型**：事实走 Tool（MySQL），话术走模型，RAG 可关可降级。

向量库存什么（摘要）：

| 类型 | 文档 ID | metadata |
| --- | --- | --- |
| 上架书目 | `book:{id}` | `type=book`，含 bookId / categoryId / status |
| FAQ | `faq:{index}` | `type=faq`，含 topic |

管理端：`POST /api/ai/admin/reindex`、`/reindex-faq`。

**S4 验收**：

```text
□ 关闭 RAG 时查书 / FAQ / 推荐仍可用
□ 开启 RAG 后语义召回能返回候选，详情仍回查 MySQL
□ 未登录调个人借阅 Tool 有明确提示而非编造
```
