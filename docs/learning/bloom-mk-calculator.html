布隆过滤器：m / k 交互演算

拖动预期元素数 n 与目标假阳性率 p， 实时计算位图长度 m、哈希个数 k 与粗算内存。 与仓库 BloomFilterSpec.of 一致（m ≥ 64，k ∈ [1, 16]）。

输入参数

公式（代入当前值）

m = ⌈ −n·ln(p) / (ln 2)² ⌉
k = round( (m/n)·ln 2 )

计算结果

m（bit）
—
位数组长度
k
—
哈希函数个数
内存粗算
—
⌈m/8⌉ bytes
bits / 元素
—
m / n

曲线：固定当前 n，横轴为 p，纵轴为 m（左）与 k（右）

m（左轴，bit） k（右轴，裁剪前） 竖线 = 当前选定的 p

直观：p 越小 → m 越大；n 越大 → m 越大。 k 过大收益递减，本仓库将 k 限制在 [1, 16]。
