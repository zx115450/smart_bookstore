# 前端部署指南

> **项目**：smart_bookstore（智慧书城） · **文档类型**：学习文档  
> **关联**：仓库内 `nginx-smart-bookstore/` 便携 Nginx + 前端静态包；亦可对接独立前端仓库  
> **索引**：[学习文档中心](./README.md)

本仓库主体为 Spring Boot 后端。前端有两种常见用法：

1. **仓库自带演示包**（推荐上手）：`nginx-smart-bookstore/`，Windows 双击即可打开页面并反代 `/api`
2. **独立前端工程**：Vite 开发（默认 `5173`），或自行打包后部署到服务器 Nginx

---

## 0. 仓库内便携 Nginx（本地 / 演示）

目录：`nginx-smart-bookstore/`

| 项 | 说明 |
| --- | --- |
| 入口 | 双击 `start.bat`（或本目录下执行 `nginx.exe`） |
| 页面 | [http://localhost:8088](http://localhost:8088) |
| 静态资源 | `html/`（已放入构建产物） |
| API | `conf/nginx.conf` 中 `location /api/` → `http://127.0.0.1:8081` |
| 停止 | `stop.bat` |
| 更新前端 | `update-frontend.bat`（在上级前端工程执行 `npm run build` 后同步到 `html/`） |

前置条件：后端已用 `local` profile 启动在 `8081`。

关键配置摘录（完整见 `nginx-smart-bookstore/conf/nginx.conf`）：

```nginx
server {
    listen       8088;
    root         html;
    index        index.html;

    location /api/ {
        proxy_pass http://127.0.0.1:8081;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_read_timeout 120s;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

使用该入口时，后端 OAuth / 签到回调建议改为 `8088`：

```yaml
auth:
  oauth:
    qq:
      frontend-success-url: http://localhost:8088/oauth/qq/success
      frontend-error-url: http://localhost:8088/oauth/qq/error
checkin:
  frontend-base-url: http://localhost:8088
```

必须从 `nginx-smart-bookstore/` 目录启动 `nginx.exe`，否则找不到相对路径下的 `conf/` 与 `html/`。

## 整体流程（独立前端 / 生产）

```text
配置生产环境变量 → npm run build → 上传 dist/
→ Nginx 托管静态资源（可选反代 /api）→ 改后端前端回调 URL → HTTPS
```

纯 SPA 场景下，服务器 **一般不需要再安装 Node 运行前端**，只需托管构建产物。

---

## 1. 本地构建准备

### 1.1 生产环境变量

在前端项目中配置生产 API 地址（示例为 Vite）：

```bash
# .env.production
VITE_API_BASE_URL=https://your.domain.com
# 若前后端同域并由 Nginx 反代，可写相对路径：
# VITE_API_BASE_URL=
```

演示包走 Nginx 同域反代时，前端请求应使用相对路径 `/api/...`，不要把 `http://localhost:8081` 打进生产 / 演示包。

### 1.2 安装依赖并打包

```bash
npm ci
# 或 pnpm i / yarn install
npm run build
```

### 1.3 确认产物目录

| 框架 | 常见产物目录 |
| --- | --- |
| Vite（React / Vue） | `dist/` |
| Create React App | `build/` |
| Next.js（纯静态导出） | `out/`（需 `output: 'export'`） |
| Next.js（SSR） | 需 Node 进程，不按本文「纯静态」部署 |

构建完成后应看到 `index.html` 与带 hash 的 `assets/`。同步到本仓库演示 Nginx：

```text
将 dist/* 覆盖到 nginx-smart-bookstore/html/
然后在 nginx-smart-bookstore 目录执行：nginx.exe -s reload
```

或使用目录内的 `update-frontend.bat`（脚本假定前端工程在上级目录并执行 `npm run build`）。

---

## 2. 上传到服务器

任选一种方式：

```bash
# scp 示例
scp -r dist/* user@server:/var/www/bookstore-frontend/

# rsync 示例（推荐增量同步）
rsync -avz --delete dist/ user@server:/var/www/bookstore-frontend/
```

也可在 CI（GitHub Actions 等）中构建后上传，或使用 Docker 多阶段构建（最终镜像：Nginx + `dist`）。

建议服务器目录：

```text
/var/www/bookstore-frontend/
  index.html
  assets/
  ...
```

---

## 3. Nginx 配置要点

1. `root` 指向前端产物目录
2. SPA 路由：刷新子路径时回退到 `index.html`
3. 同域时用 `location /api/` 反代到本后端（默认 `8081`）
4. 生产环境配置 HTTPS（Let’s Encrypt 等）

示意配置（生产域名）：

```nginx
server {
    listen 80;
    server_name your.domain.com;
    root /var/www/bookstore-frontend;
    index index.html;

    location /api/ {
        proxy_pass http://127.0.0.1:8081;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

本地演示可直接复用仓库内 `nginx-smart-bookstore/conf/nginx.conf`（监听 `8088`）。

前后端 **不同域** 时，需在后端配置 CORS，并保证前端请求带上正确的 `Authorization` 头；同域反代通常更简单。

## 4. 与本后端对齐的配置

后端默认仍可能指向 Vite `5173`。使用本仓库 Nginx 或生产域名后，请通过 `application-local.yaml` / 环境变量覆盖：

| 配置项 / 环境变量 | 用途 | 本仓库 Nginx 示例 | 生产示例 |
| --- | --- | --- | --- |
| `QQ_FRONTEND_SUCCESS_URL` | QQ OAuth 成功回调页 | `http://localhost:8088/oauth/qq/success` | `https://your.domain.com/oauth/qq/success` |
| `QQ_FRONTEND_ERROR_URL` | QQ OAuth 失败回调页 | `http://localhost:8088/oauth/qq/error` | `https://your.domain.com/oauth/qq/error` |
| `CHECKIN_FRONTEND_URL` | 签到相关前端基址 | `http://localhost:8088` | `https://your.domain.com` |

对应源配置见 `src/main/resources/application.yaml`。

后端启动示例：

```bash
mvn spring-boot:run -Dspring-boot.run.profiles=local
# 默认端口 8081
```

## 5. 上线检查清单

| 检查项 | 说明 |
| --- | --- |
| 页面可打开 | 本地：`http://localhost:8088`；生产：`https://your.domain.com` |
| 接口可达 | DevTools → Network，确认 `/api/...` 为 200（经 Nginx 反代） |
| 登录与 Token | 同域或 CORS + 请求头正确 |
| 刷新不 404 | 依赖 Nginx `try_files ... /index.html` |
| 静态缓存 | `index.html` 短缓存；带 hash 的 `assets` 可长缓存（演示配置已设 7d） |
| 构建环境 | 包内无写死的 localhost:8081 |
| OAuth / 签到 | 后端前端回调 URL 已与实际前端地址一致 |
| 后端在线 | `8081` 已启动，否则页面能开但接口 502 |

## 6. 可选：Docker 部署前端

```dockerfile
# 多阶段：构建
FROM node:20-alpine AS build
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# 运行：仅 Nginx + 静态文件
FROM nginx:alpine
COPY --from=build /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
```

`nginx.conf` 可参考上文 `server` 块或仓库内 `nginx-smart-bookstore/conf/nginx.conf`（注意容器内 `proxy_pass` 应指向后端服务名，而非 `127.0.0.1`，除非使用 host 网络）。
