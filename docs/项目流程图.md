## 四、工厂 + 策略模式（登录 / 发码）

```mermaid
flowchart TD
    REQ[loginType / sendCode loginType]
    REQ --> FACT{Factory 按类型选择}

    FACT -->|password| H1[PasswordLoginHandler]
    FACT -->|qq_email_code| H2[EmailCodeLoginHandler]
    FACT -->|phone_code| H3[PhoneCodeLoginHandler]

    FACT -->|qq_email_code| S1[EmailSendCodeHandler]
    FACT -->|phone_code| S2[PhoneSendCodeHandler]

    H1 --> BCrypt[BCrypt 校验密码]
    H2 --> RC1[Redis 验码]
    H3 --> RC2[Redis 验码]

    S1 --> RS1[Redis 存码 + 发邮件]
    S2 --> RS2[Redis 存码]

    BCrypt --> USER[AuthUser]
    RC1 --> USER
    RC2 --> USER
    USER --> SESSION[创建 Session + 双 Token]
```

**Spring 注入：** `List<LoginHandler>` / `List<SendCodeHandler>` 自动收集所有 `@Component` 实现。

## 五、发送验证码流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant AC as AuthController
    participant AS as AuthService
    participant AR as AuthRedisService
    participant SF as SendCodeHandlerFactory
    participant H as Email/PhoneSendCodeHandler
    participant R as Redis
    participant M as Mail(可选)

    C->>AC: POST /api/auth/code/send
    AC->>AS: sendCode(req, ip)
    AS->>AR: checkSendCodeRateLimit(target, ip)
    alt 触发限流
        AR-->>C: 1002 发送太频繁
    end
    AS->>SF: getHandler(loginType)
    SF->>H: handle(req, ip)
    H->>H: 生成 6 位验证码
    H->>R: SET auth:code:{type}:{scene}:{target} = hash, TTL 300s
    opt 邮箱登录
        H->>M: 发送邮件
    end
    H-->>C: { expiresIn: 300 }
```

## 六、登录流程（统一入口）

```mermaid
sequenceDiagram
    participant C as 客户端
    participant AC as AuthController
    participant AS as AuthService
    participant AR as AuthRedisService
    participant LF as LoginHandlerFactory
    participant H as LoginHandler
    participant RR as AuthRoleRepository
    participant SR as AuthSessionRepository
    participant JS as JwtService
    participant DB as MySQL
    participant R as Redis

    C->>AC: POST /api/auth/login
    AC->>AS: login(req, ip, userAgent)
    AS->>AR: checkLoginAllowed(loginKey)
    AS->>LF: getHandler(loginType)
    LF->>H: handle(req, ip)

    alt 密码登录
        H->>DB: 查用户 + BCrypt matches
    else 验证码登录
        H->>R: verifyAndConsumeCode (GET + DEL)
        H->>DB: 查/建用户 + identity
    end

    alt 登录失败
        AS->>AR: recordLoginFailure
        AS->>DB: 写 auth_login_audit (fail)
        AC-->>C: 1001
    end

    AS->>RR: ensureDefaultUserRole → USER
    AS->>AR: clearLoginFailure
    AS->>SR: save auth_session
    SR->>DB: INSERT session
    SR->>R: cache session
    AS->>JS: createAccessToken(userId, username, sid, roles)
    AS->>DB: 写 auth_login_audit (success)
    AC-->>C: accessToken + refreshToken + userInfo
```

## 七、JWT 鉴权流程（受保护 API）

```mermaid
sequenceDiagram
    participant C as 客户端
    participant JF as JwtAuthenticationFilter
    participant JS as JwtService
    participant AR as AuthRedisService
    participant SR as AuthSessionRepository
    participant SC as AuthSessionCacheService
    participant DB as MySQL
    participant R as Redis
    participant UC as UserController

    C->>JF: GET /api/user/me + Bearer accessToken

    JF->>JS: parseAccessToken
    alt Token 过期
        JF-->>C: 401 code 2002
    end

    JF->>AR: isAccessBlacklisted(jti)?
    alt 在黑名单
        JF-->>C: 401 code 2006
    end

    JF->>SR: findById(sessionId)
    SR->>SC: getById
    alt 缓存命中
        SC->>R: GET auth:session:id:*
    else 缓存未命中
        SR->>DB: SELECT auth_session
        SR->>SC: cache(session)
    end

    alt session 已撤销
        JF-->>C: 401 code 2004
    end

    JF->>DB: 查 auth_user.status
    JF->>JF: 设置 SecurityContext + AuthPrincipal
    JF->>UC: 放行
    UC->>UC: PreAuthorize hasRole USER
    UC-->>C: 200 userInfo
```

**公开接口（不过滤器）：** `/api/auth/login`、`/refresh`、`/code/send`、`/logout`

## 八、Refresh Token 刷新（Rotation）

```mermaid
sequenceDiagram
    participant C as 客户端
    participant AC as AuthController
    participant AS as AuthService
    participant SR as AuthSessionRepository
    participant SC as AuthSessionCacheService
    participant JS as JwtService
    participant DB as MySQL
    participant R as Redis

    C->>AC: POST /api/auth/refresh<br/>Body: jti:secret
    AC->>AS: refresh(refreshToken)

    AS->>SR: findByRefreshTokenJti(jti)
    SR->>SC: getByRefreshTokenJti
    alt 缓存未命中
        SR->>DB: SELECT by jti
    end

    alt session 已撤销（重放攻击）
        AS->>SR: revokeAllByUserId
        AC-->>C: 2001
    end

    alt 过期 / hash 不匹配
        AC-->>C: 2001
    end

    AS->>SR: 旧 session revoked_at = now
    SR->>SC: evict(旧 session)
    AS->>SR: INSERT 新 session（新 jti）
    SR->>SC: cache(新 session)
    AS->>JS: 签发新 Access JWT
    AC-->>C: 新 accessToken + 新 refreshToken
```

> **注意：** 每次刷新后 Refresh Token 会变化，前端必须覆盖保存。

## 九、登出流程

```mermaid
sequenceDiagram
    participant C as 客户端
    participant AC as AuthController
    participant AS as AuthService
    participant JS as JwtService
    participant AR as AuthRedisService
    participant SR as AuthSessionRepository
    participant DB as MySQL
    participant R as Redis

    C->>AC: POST /api/auth/logout<br/>Authorization: Bearer access<br/>Body: refreshToken(可选)
    AC->>AS: logout(access, refresh)

    opt Access Token 有效
        AS->>JS: parseAccessToken
        AS->>AR: blacklistAccessToken(jti, TTL)
        AS->>SR: revokeById(sessionId)
        SR->>DB: UPDATE revoked_at
        SR->>R: evict session cache
    end

    opt Refresh Token 提供
        AS->>SR: findByRefreshTokenJti → revokeById
    end

    AC-->>C: success
```

## 十、Session 缓存（Cache-Aside）

```mermaid
flowchart TD
    Q[查询 Session] --> C1{Redis 有缓存?}
    C1 -->|是| R1[返回快照]
    C1 -->|否| DB[查 MySQL]
    DB --> W[写入 Redis<br/>TTL = refresh 剩余时间]
    W --> R1
    R1 --> U[加载 AuthUser]

    S[save / revoke Session] --> DBW[写 MySQL]
    DBW --> E{revoked?}
    E -->|是| DEL[删除 Redis key]
    E -->|否| PUT[更新 Redis 缓存]
```

## 十三、端到端用户旅程

```mermaid
flowchart TD
    START([用户打开应用]) --> CHOICE{登录方式}

    CHOICE -->|密码| PWD[POST /login password]
    CHOICE -->|邮箱验证码| EM1[POST /code/send]
    CHOICE -->|手机验证码| PH1[POST /code/send]

    EM1 --> EM2[POST /login qq_email_code]
    PH1 --> PH2[POST /login phone_code]

    PWD --> TOKENS[获得 access + refresh]
    EM2 --> TOKENS
    PH2 --> TOKENS

    TOKENS --> API[携带 Bearer 访问 /api/user/me]
    API --> CHECK{Access 有效?}
    CHECK -->|是| OK[200 返回用户信息]
    CHECK -->|401 过期| REF[POST /refresh]
    REF --> NEW[更新 Token]
    NEW --> API
    REF -->|2001 失败| LOGIN[重新登录]
    OK --> LOGOUT{用户退出?}
    LOGOUT -->|是| OUT[POST /logout]
    OUT --> END([清除 Token])
    LOGOUT -->|否| API
```

## 十四、错误码速查

| code | HTTP | 场景 |
|------|------|------|
| 0 | 200 | 成功 |
| 1001 | 200 | 登录凭证错误 |
| 1002 | 200 | 参数错误 / 限流 |
| 2001 | 200 | Refresh 无效 |
| 2002 | 401 | Access 过期 |
| 2003 | 401 | Token 无效 / 未授权 |
| 2004 | 401 | Session 已撤销 |
| 2005 | 401 | 用户禁用 |
| 2006 | 401 | Access 已拉黑（登出） |
| 3001 | 403 | 无权限 |
