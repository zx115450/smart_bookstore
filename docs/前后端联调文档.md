# 前后端联调说明

## 1. 前端配置

在项目根目录创建 `.env` 文件，内容参考：

```env
VITE_API_BASE_URL=http://localhost:8080
```

说明：

- `VITE_API_BASE_URL` 用来配置后端服务地址。
- 如果你的后端部署在别的端口或域名，把这里改成实际地址即可。
- 修改环境变量后，需要重启前端开发服务器。

## 2. 后端需要提供的接口

当前前端会调用以下接口：

### 2.1 发送验证码

`POST /api/auth/code/send`

请求体示例：

```json
{
  "loginType": "qq_email_code",
  "target": "user@qq.com",
  "scene": "login"
}
```

`loginType` 可取：

- `qq_email_code`
- `phone_code`

### 2.2 登录

`POST /api/auth/login`

QQ 邮箱验证码登录示例：

```json
{
  "loginType": "qq_email_code",
  "email": "user@qq.com",
  "code": "123456",
  "rememberMe": true
}
```

手机号验证码登录示例：

```json
{
  "loginType": "phone_code",
  "phone": "13800138000",
  "code": "123456",
  "rememberMe": true
}
```

账号密码登录示例：

```json
{
  "loginType": "password",
  "account": "admin",
  "password": "123456",
  "rememberMe": true
}
```

## 3. 后端返回格式建议

建议统一返回如下结构：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "accessToken": "xxx",
    "refreshToken": "yyy",
    "expireIn": 7200,
    "userInfo": {
      "id": 1,
      "username": "admin"
    }
  }
}
```

前端会优先读取：

- `message`
- `data.accessToken`
- `data.refreshToken`
- `data.userInfo`

如果你的返回字段不同，可以在前端的 `src/App.vue` 中调整解析逻辑。

## 4. 联调步骤

1. 启动后端服务，确认接口地址可访问。
2. 在前端根目录创建 `.env` 文件并配置 `VITE_API_BASE_URL`。
3. 执行 `npm install`。
4. 执行 `npm run dev` 启动前端。
5. 打开浏览器访问 Vite 输出的本地地址。
6. 先测试验证码发送接口，再测试三种登录方式。

## 5. 常见问题

### 5.1 浏览器跨域报错

如果前后端端口不同，需要后端开启 CORS，或者在 Vite 中配置代理。

### 5.2 页面显示请求失败

先检查：

- 后端服务是否启动
- `VITE_API_BASE_URL` 是否写对
- 接口路径是否与后端一致
- 返回体是否是合法 JSON

### 5.3 修改环境变量后不生效

修改 `.env` 后，需要重新启动前端开发服务器。
