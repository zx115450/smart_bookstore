Smart Bookstore - Portable Nginx
================================

Folder: nginx-smart-bookstore\

Start:
  double-click start.bat   (recommended)
  or nginx.exe

URL:  http://localhost:8088
API:  proxy /api -> http://127.0.0.1:8081

Require: Spring Boot backend running on 8081

Stop:   stop.bat
Update: update-frontend.bat  (npm run build + sync html)

Always run nginx.exe from THIS folder.
